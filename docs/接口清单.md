# 接口清单（40+ 端点）

> 统一前缀 `/api`，统一返回 `{code, msg, data}`；除标注"公开"外需 `Authorization: Bearer <token>`。
> 管理员专属接口由 JwtInterceptor 校验（role=admin）。

## 用户 `/api/user`
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /user/login | 登录（失败限流 5 次/15 分钟；端角色校验）公开 |
| POST | /user/logout | 登出（JWT 加入 Redis 黑名单） |
| POST | /user/register | 注册（BCrypt）公开 |
| GET | /user/info | 当前用户信息 |
| PUT | /user/update | 修改资料/密码 |

## 景点 `/api/spot`
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /spot/list | 景点列表 公开 |
| GET | /spot/detail/{id} | 景点详情 公开 |
| POST | /spot/add | 新增 管理员 |
| PUT | /spot/update | 修改 管理员 |
| DELETE | /spot/delete/{id} | 删除 管理员 |

## 票种与时段 `/api/ticket`
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /ticket/list | 票种列表（可按 spotId）公开 |
| GET | /ticket/slots | 时段列表（可按 policyId）公开 |
| GET | /ticket/slots/spot | 按景点获取时段 公开 |
| GET | /ticket/slot/{id} | 单个时段 公开 |
| POST/PUT/DELETE | /ticket/add|update|delete/{id} | 票种维护 管理员 |
| POST/PUT/DELETE | /ticket/slot/add|update|delete/{id} | 时段维护 管理员 |

## 订单 `/api/order`
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /order/list | 订单列表（分页/状态/关键字；游客仅本人可见） |
| GET | /order/detail/{id} | 订单详情 |
| POST | /order/create | 下单（Redis 锁 + 库存校验 防超卖） |
| POST | /order/pay/{id} | 支付（返回 alipay/mock 跳转） |
| POST | /order/refund-apply/{id} | 游客申请退款 |
| POST | /order/refund/{id} | 管理员审核退款 |
| POST | /order/cancel-refund/{id} | 取消退款申请 |
| DELETE | /order/batch-delete | 批量删除 管理员 |
| PUT | /order/hide | 游客隐藏订单 |

## 支付回调 `/api/pay`
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /pay/notify/alipay | 支付宝异步回调（验签/幂等/金额校验）公开 |
| POST | /pay/mock/confirm/{id} | 模拟支付确认（演示） |
