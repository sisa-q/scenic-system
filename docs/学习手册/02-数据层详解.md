## 2.0 JPA 前置知识（30 秒入门）

JPA（Java Persistence API）是 ORM：**Java 类 = 数据库表，对象 = 一行记录**。

常用注解：
| 注解 | 含义 |
|---|---|
| `@Entity` | 声明这是数据库实体类 |
| `@Table(name="t_xxx", indexes=...)` | 对应表名 + 索引 |
| `@Id` + `@GeneratedValue(IDENTITY)` | 主键，自增 |
| `@Column(unique, nullable, length, columnDefinition)` | 列约束 |
| `@Transient` | 该字段**不存数据库**（仅用于给前端展示的关联数据） |
| `@CreationTimestamp` / `@UpdateTimestamp` | 插入/更新时自动填时间 |
| `@JsonFormat` | 前端 JSON 序列化格式 |
| `@JsonProperty(WRITE_ONLY)` | 序列化时隐藏（密码不回传前端） |

## 2.1 十张表总览

| 实体类 | 表名 | 含义 |

| `FlowStat` | `t_flow_stat` | 客流统计快照 |

**表关系（核心链路）**：
```
景点 ScenicSpot 1 ── 多 TicketPolicy 1 ── 多 TimeSlot
                        ↑
订单 Order（选某票种+某时段，绑定 user）
```
订单 → 支付流水（1:1）→ 核销记录（1:1）→ 客流统计（核销驱动）

## 2.2 核心实体逐个讲

### ① User —— 用户表
```java
@Table(name = "t_user", indexes = @Index(name="idx_user_phone", columnList="phone"))
public class User {
    @Id @GeneratedValue(IDENTITY) private Long id;   // 主键自增
    @Column(unique=true, nullable=false) private String username;  // 唯一用户名
    private String password;   // @JsonProperty(WRITE_ONLY)：密码永不下发前端
    private String nickname;   // 昵称
    private String phone;      // 手机号（建索引，按手机查用户）
    private String avatar;     // 头像
    private String role = "user";  // 角色：user 游客 / admin 管理员
    @CreationTimestamp private Date createTime;      // 注册时间
}
```
> 面试点：为什么密码用 `@JsonProperty(WRITE_ONLY)`？防止登录接口把密码哈希泄露给前端。

### ② ScenicSpot —— 景点表
字段：`id / name / location / description / imageUrl / capacity（容量）/ status（1启用 0停用）/ createTime / updateTime`
- 故宫 capacity=80000，其它模型景点 10

### ③ TicketPolicy —— 票种表（挂在景点下）
字段：`id / spotId（所属景点）/ name（成人票）/ price（BigDecimal）/ totalQuota（总配额）/ refundRule（退改规则）/ status`
- `@Transient String spotName`：不存库，查询时手动填充用于前端显示

### ④ TimeSlot —— 时段表（挂在票种下）
字段：`id / policyId / startTime / endTime / quota（该场次总名额）/ booked（已约数）/ status`
- 关键字段：`booked` —— 防超卖就是在这个字段上做文章（Redis 锁 + 数据库校验）

### ⑤ Order —— 订单表（核心）
```java
@Table(name="t_order", indexes = {idx_order_user, idx_order_status, idx_order_slot})
public class Order {
    Long id;
    Long userId;            // 下单用户
    @Column(unique=true) String orderNo;   // 业务订单号（支付宝 out_trade_no）
    Long policyId;          // 票种
    Long slotId;            // 时段
    Integer quantity;       // 数量
    BigDecimal totalAmount; // 总金额
    Integer status = 0;     // ★ 订单状态机
    Date payTime;           // 支付时间
    Date useTime;           // 核销时间
    Date refundTime;        // 退款时间
    Date refundRequestTime; // 退款申请时间
    Integer userVisible = 1;// 游客是否可见（可隐藏）
    // @Transient 关联展示字段：spotName/policyName/startTime/endTime/price/disabled
}
```

**★ 订单状态机（重点）**：`status` 取值
| 值 | 含义 |
|---|---|
| 0 | 待支付 |
| 1 | 已支付 |
| 2 | 已核销（入园） |
| 3 | 已退款 |
| 4 | 已失效（支付超时自动作废） |
| 5 | 退款申请中（游客申请→管理员审核） |

流转：`0 --支付--> 1 --核销--> 2`；`0 --超时--> 4`；`1/2 --退款--> 3`（经 5 中转）。

### ⑥ PayTransaction —— 支付流水表
字段：`id / orderNo / channel（alipay|mock）/ transactionId（支付宝 trade_no）/ amountFen（金额，单位分）/ status / notifyTime / rawData（回调原始报文）`
- 作用：记录支付宝回调，**幂等**（同 trade_no 只处理一次）、对账

### ⑦ VerifyRecord —— 核销记录表
字段：`id / orderNo / userId / verifyCode（核销码）/ verifyTime / operator`
- 管理员在后台输入核销码 → 校验订单已支付 → 生成核销记录 + 改订单 status=2

### ⑧ Evaluation —— 评价表
字段：`id / orderId / spotId / userId / rating（1-5星）/ content / createTime`

### ⑨ Notice —— 公告表
字段：`id / title / content / status / createTime`

### ⑩ FlowStat —— 客流统计表
字段：`id / spotId / statTime / inCount / outCount / currentCount`
- 由核销记录/模拟引擎写入，供大屏 ECharts 与 WebSocket 推送

## 2.3 repository 包 —— JPA 数据访问（10 个接口）

**通用模式**：`interface XxxRepository extends JpaRepository<实体, Long>` 就自动获得
`save / findById / findAll / deleteById / count` 等基础方法，**无需写 SQL**。

**Spring Data JPA 方法命名规则**（重点，面试常考）：
`findBy + 字段名 + [And/Or] + 字段名`，框架自动生成查询。例：

```java
// OrderRepository（最丰富，含分页）
List<Order> findByUserId(Long userId);                 // WHERE user_id = ?
List<Order> findByStatus(Integer status);              // WHERE status = ?
Optional<Order> findByOrderNo(String orderNo);         // 按业务订单号查（支付宝回调用）
long countBySlotIdAndStatusIn(Long slotId, List<Integer> s); // 某时段已支付数（库存校验）
Page<Order> findByStatusAndOrderNoContaining(Integer status, String key, Pageable p);
// ↑ 分页 + 模糊查询（Pageable 传 page/size，返回 Page 对象）
```

**10 个 Repository 一览**：
| 接口 | 特色方法 |
|---|---|
| `UserRepository` | `findByUsername` / `findByPhone`（登录） |
| `ScenicSpotRepository` | 基础方法即可 |
| `TicketPolicyRepository` | `findBySpotId`（某景点的票种） |
| `TimeSlotRepository` | `findByPolicyId` / `findByPolicyIdIn`（时段） |
| `OrderRepository` | 订单分页/状态/用户/订单号查询（如上） |
| `PayTransactionRepository` | `findByTransactionId`（幂等） |
| `VerifyRecordRepository` | `findByVerifyCode`（核销） |
| `EvaluationRepository` | `findBySpotId` / 分页 |
| `NoticeRepository` | `findByStatusOrderByCreateTimeDesc`（公告列表） |
| `FlowStatRepository` | `findTop...OrderByStatTimeDesc`（最新客流） |
