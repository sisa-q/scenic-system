# 第 6 章 · 前端详解（二）：管理端 admin

> 学习目标：看懂管理后台的布局与九个功能页面，以及它和游客端的异同。
> 技术栈：Vue 3 + **Element Plus** + Pinia + Vue Router + Axios + Three.js（客流大屏）

---

## 6.1 与游客端的异同

| 对比项 | 游客端 web | 管理端 admin |
|---|---|---|
| UI 库 | Vant 4（移动端风格） | Element Plus（桌面后台风格） |
| 入口端口 | 8080 | 8081 |
| 登录限制 | 只允许游客账号 | 只允许管理员账号（`end=admin`） |
| api/utils/components/web | **结构完全一样**（api 10 个、utils 同款、FlowScene 共用） | 同左 |
| 页面 | 游客操作页 | 后台管理页（在 Layout 布局内） |

> 两个前端共享同一套后端接口，只是 UI 和功能视角不同。

## 6.2 入口与骨架

### main.js
```js
app.use(ElementPlus)                 // Element Plus 组件库
// 注册所有图标：app.component(key, component)
app.use(router); app.use(createPinia())
```

### router/index.js —— 管理端路由
- `/login`：独立管理员登录页
- `/admin`：布局路由（`Layout/Index.vue`），children 挂 9 个页面：
  `dashboard` 客流大屏 / `spot` 景点管理 / `ticket` 票务策略 / `timeslot` 分时时段 /
  `order` 订单管理 / `evaluation` 评价管理 / `notice` 公告发布 / `verify` 核销管理 / `profile` 个人中心
- 守卫：**只允许 admin 角色**，残留游客令牌一律清除；未登录跳登录页

## 6.3 components/admin —— 后台布局组件

| 组件 | 作用 |
|---|---|
| `Layout/Index.vue` | 整体布局：左 Sidebar + 上 Header + 内容区 router-view |
| `Layout/Sidebar.vue` | 侧边菜单（根据路由 meta.title/icon 渲染） |
| `Layout/Header.vue` | 顶栏（标题/用户/退出） |
| `Common/Breadcrumb.vue` | 面包屑导航 |
| `Common/Pagination.vue` | 分页组件（复用） |

## 6.4 views/admin —— 九个管理页面

| 页面 | 作用 | 关键功能 |
|---|---|---|
| `Dashboard.vue` | ★ 客流大屏 | 嵌入 `FlowScene.vue` + threeScene 3D 故宫，连 `/ws/flow` WebSocket 每 5 秒刷真实客流，30 秒拖拽回放 |
| `SpotManage.vue` | 景点管理 | 列表/新增/编辑/启停用（调 spot api） |
| `TicketPolicy.vue` | 票务策略 | 票种 CRUD + 价格/库存/退改规则 |
| `TimeSlotManage.vue` | 分时时段 | 时段 CRUD + 自动补未来 7 天 |
| `OrderManage.vue` | 订单管理 | 全部订单 + 状态筛选 + 分页 + 退款审核 + 核销 |
| `VerifyManage.vue` | 核销管理 | 输入核销码核销入园 + 核销记录列表 |
| `Evaluation.vue` | 评价管理 | 评价列表/删除 |
| `NoticeManage.vue` | 公告发布 | 公告 CRUD |
| `Profile.vue` | 个人中心 | 修改密码/资料 |
| `Login.vue` | 管理员登录 | `end=admin` 端角色校验 |

## 6.5 管理端核心操作流（跟着走一遍）

```
登录（admin/admin123）
→ OrderManage：看到游客订单，点"核销"或在 VerifyManage 输入核销码
→ 核销成功 → Dashboard 客流大屏实时人数 +1（WebSocket 推送）
→ TicketPolicy/TimeSlot：维护票种时段
→ NoticeManage：发公告（游客首页顶部轮播）
→ Evaluation：管理评价
```

## 6.6 面试常问：管理端权限怎么做的？

1. 前端：路由守卫拦截 + 菜单只渲染 admin 可见项（不够安全，只防君子）
2. **真正的权限在后端**：JwtInterceptor 的 `ADMIN_ONLY_PREFIXES` 白名单 + Controller 里 role 判断（防小人）
> 记住：**前端限制只是体验，后端校验才是安全**。
