# 第 1 章 · 后端框架与核心配置详解

> 学习目标：看懂 Spring Boot 工程怎么搭起来、每个配置类/工具类干什么。
> 本章覆盖：pom.xml、启动类、application.yml、config 包全部、interceptor、util、vo。

## 1.1 pom.xml —— Maven 依赖清单

路径：`houduana/pom.xml`

Maven 是 Java 的"包管理器"，pom.xml 声明项目依赖哪些库。核心依赖逐个解释：

| 依赖 | 干什么用 |
|---|---|
| `spring-boot-starter-web` | 内置 Tomcat，提供 HTTP 接口（Controller）能力 |
| `spring-boot-starter-data-jpa` | 用 JPA 操作数据库（Hibernate 实现，自动建表、ORM 映射） |
| `mysql-connector-j` | MySQL 驱动（Java 连 MySQL 的桥梁） |
| `lombok` | 用 `@Data` 自动生成 getter/setter，少写样板代码 |
| `spring-boot-devtools` | 热部署（改代码自动重启） |
| `spring-boot-starter-test` + `h2` | 测试框架 + H2 内存数据库（测试不依赖真实 MySQL） |
| `spring-boot-starter-websocket` | WebSocket（客流大屏实时推送、天气预警推送） |
| `spring-boot-starter-data-redis` | Redis（分布式锁防超卖 + 缓存三防） |
| `jjwt-api/impl/jackson` | JWT 工具库（生成/解析登录令牌） |
| `spring-security-crypto` | 只引入 BCrypt 加密组件（不引入整个安全框架） |
| `jacoco-maven-plugin` | 测试覆盖率统计插件 |

> 注意：这里**故意不引入** `spring-boot-starter-security`，只用它的 crypto 工具，
> 避免安全框架默认拦截所有请求，简化开发。

## 1.2 启动类 HouduanaApplication

路径：`houduana/src/main/java/com/scenic/HouduanaApplication.java`

```java
@SpringBootApplication   // 组合注解：自动配置 + 组件扫描 + 配置类
@EnableScheduling        // 开启定时任务（客流每5秒推送、天气每30分钟检测）
public class HouduanaApplication {
    public static void main(String[] args) {
        SpringApplication.run(HouduanaApplication.class, args);
    }
}
```

- `@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`
- 它扫描 `com.scenic` 包下所有带 `@Component/@Service/@Repository/@Controller` 的类并注册为 Bean

## 1.3 application.yml —— 默认配置

路径：`houduana/src/main/resources/application.yml`

```yaml
server:
  port: 8083                 # 后端端口（前端 /api 代理到这里）

spring:
  datasource:                # 数据库连接
    url: jdbc:mysql://localhost:3306/digital_ticket?...
    username: root
    password: ...
  jpa:
    hibernate.ddl-auto: update   # 启动时自动建表/更新表结构（开发期神器）
  data.redis:                    # Redis 连接（localhost:6379）
    ...
  jackson.date-format: yyyy-MM-dd HH:mm:ss   # 统一时间格式

jwt:
  secret: abc...             # JWT 签名密钥
  expire: 86400000           # token 有效期（毫秒）≈ 24 小时

pay:
  enabled: ${PAY_ENABLED:false}      # 默认关闭（mock），环境变量可覆盖
  channel: ${PAY_CHANNEL:mock}       # 支付通道：mock | alipay
  app-id: ${PAY_APP_ID:}
  private-key: ${PAY_PRIVATE_KEY:}
  alipay-public-key: ${PAY_PUBLIC_KEY:}
  server-url: ${PAY_SERVER_URL:https://openapi-sandbox.dl.alipaydev.com/gateway.do}
  notify-url: ${PAY_NOTIFY_URL:}
  return-url: ${PAY_RETURN_URL:}

logging:
  level:
    com.scenic: debug        # 打印业务包 debug 日志
    org.springframework.web: debug
```

> **三个 profile 文件关系**：`application.yml` 是底，`application-local.yml` / `application-prod.yml`
> 用同名 key 覆盖它。所以 local 里只写了 pay 的密钥，其它配置继承默认。

## 1.4 config 包 —— 10 个配置类逐个讲

### ① WebConfig —— 注册 JWT 拦截器 + 白名单
路径：`config/WebConfig.java`
- 实现 `WebMvcConfigurer`，用 `addInterceptors` 把 `JwtInterceptor` 挂到所有 `/api/**` 请求上
- `excludePathPatterns` 列出**不需要登录**的接口（登录/注册/景点列表/票种/公告/天气/支付回调）

### ② CorsConfig —— 跨域放行
路径：`config/CorsConfig.java`
- `addCorsMappings("/api/**")` 允许任意来源跨域访问
- 开发期前端 8080/8081 访问后端 8083 需要它

### ③ PasswordConfig —— BCrypt 密码加密
路径：`config/PasswordConfig.java`
```java
@Bean
public BCryptPasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder(12); // strength=12，加盐哈希，抗暴力破解
}
```

### ④ GlobalExceptionHandler —— 全局异常处理
路径：`config/GlobalExceptionHandler.java`
- `@RestControllerAdvice`：所有 Controller 抛出的异常统一在这里处理
- `RuntimeException` → 返回 `Result.error(异常信息)`（业务校验失败信息透传给前端）
- `Exception` → 返回"服务器内部错误"（兜底）

### ⑤ WebSocketConfig —— WebSocket 端点注册
路径：`config/WebSocketConfig.java`
- 注册两个 WebSocket 端点：`/ws/flow`（客流大屏）、`/ws/weather`（天气预警）
- `setAllowedOrigins("*")` 允许跨域连接

### ⑥ FlowWebSocketHandler —— 客流大屏实时推送
路径：`config/FlowWebSocketHandler.java`
- 用 `CopyOnWriteArraySet` 保存所有在线大屏连接
- `@Scheduled(fixedDelay = 5000)` 每 5 秒调用 `flowStatService.getRealtime()` 取实时客流，广播给所有连接

### ⑦ WeatherWebSocketHandler —— 天气预警推送
路径：`config/WeatherWebSocketHandler.java`
- 连接后前端发送 `{type:"subscribe", points:[{spotId,name,lat,lng}]}` 订阅景点
- `@Scheduled(fixedDelay = 1800000)` 每 30 分钟调 `weatherService.buildAlerts(points)` 检测异常天气推送

### ⑧ DataInitializer —— 启动数据自愈
路径：`config/DataInitializer.java`
- 实现 `CommandLineRunner`：Spring 启动完成后自动执行
- 功能：① 无 admin 则创建管理员（admin/admin123，BCrypt 加密）② 旧明文密码自动迁移为 BCrypt ③ 景点表为空则种 15 个全球景点 + 故宫票种/时段 ④ 按总配额补未来 7 天时段

### ⑨ PayProperties —— 支付配置读取
路径：`config/PayProperties.java`
- 用 `@Value("${pay.xxx}")` 从 yml 读支付配置
- `@PostConstruct logPayConfig()` 启动时打印 `[Pay] enabled=true, channel=alipay, appId=...` —— **排查"为什么还是模拟支付"就靠它**

### ⑩ （见 1.5）拦截器单独讲，因为它不属 config 包

## 1.5 interceptor/JwtInterceptor —— 登录与权限拦截

路径：`interceptor/JwtInterceptor.java`

```java
@Component
public class JwtInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest req, HttpServletResponse resp, Object handler) {
        // 1. OPTIONS 预检请求直接放行（配合 CORS）
        // 2. 从 Authorization: Bearer xxx 取 token，用 JwtUtil 校验合法性
        // 3. 校验 Redis 黑名单（jwt:blacklist:jti，登出后 token 立即失效）
        // 4. 命中 ADMIN_ONLY_PREFIXES 的接口要求 role=admin，否则 403
    }
}
```

**管理员专属接口前缀**：景点/票种/时段增删改、公告发布、订单批量删除、评价管理、核销 `/api/verify`、客流 `/api/flow`。

## 1.6 util 包 —— 3 个核心工具

### ① JwtUtil —— 令牌生成/解析
路径：`util/JwtUtil.java`
- `generateToken(userId, username, role)`：生成 HS256 签名的 JWT，claims 里带 userId/username/role，附带 jti（登出黑名单用）
- `parseToken/validateToken/getUserIdFromToken/getRoleFromToken`：解析与校验
- `getRemainingMillis`：登出时算黑名单 TTL

### ② RedisCache —— 缓存三防工具（项目亮点！）
路径：`util/RedisCache.java`

封装了 **Cache-Aside（旁路缓存）** 模式：
| 能力 | 实现 |
|---|---|
| 防穿透 | 查不到也缓存空值，短 TTL（`EMPTY_TTL`） |
| 防击穿 | `getOrLoad` 用 `tryLock`（Redis `setIfAbsent` 互斥锁）保证同一时刻只有一个线程查库重建缓存 |
| 防雪崩 | 写缓存 TTL 加 0~60 秒随机抖动 |
| 降级 | Redis 不可用/超时一律当未命中，直接查库，不影响可用性 |

核心方法：`getOrLoad(key, clazz, ttl, loader)` 和 `getListOrLoad(...)`，业务方只需传一个"查数据库的 lambda"。

### ③ AlipaySigner —— 支付宝 RSA2 签名/验签
路径：`util/AlipaySigner.java`
- `sign(content, privateKey)`：SHA256withRSA 签名
- `verifyNotify(params, sign, alipayPublicKey)`：校验支付宝异步回调签名
- `buildPagePayUrl(order, props)`：构建 `serverUrl?参数&sign=...` 的电脑网站支付链接
- `callApi`：POST 调支付宝网关（预留）

## 1.7 vo 包 —— 返回给前端的数据结构

| 文件 | 作用 |
|---|---|
| `Result<T>` | 统一响应：`{code, msg, data}`；`success()` / `error()` 静态工厂 |
| `PayResult` | 支付结果：`type`（mock/alipay）、`redirectUrl`（支付宝收银台地址）、`orderId/orderNo/amount` |
| `WeatherPoint` | 天气订阅点：spotId/name/lat/lng |
| `WeatherForecast` | 天气预报：日期/天气/温度等 |
| `WeatherVO` | 天气分析面板完整视图（体感/湿度/风力/穿衣建议/3天预报） |
