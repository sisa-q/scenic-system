# 第 5 章 · 前端详解（一）：游客端 web

> 学习目标：看懂 Vue3 前端怎么组织——入口、路由、状态、API 封装、3D 地球、下单支付页面。
> 技术栈：Vue 3 + Vant 4 + Pinia + Vue Router + Axios + Three.js

---

## 5.1 入口与骨架

### main.js —— 应用入口
```js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import { createPinia } from 'pinia'
import Vant from 'vant'              // 游客端 UI 库
app.use(Vant); app.use(router); app.use(createPinia())
app.mount('#app')
```
> 注意：状态管理用的是 **Pinia**（Vue3 官方推荐，替代 Vuex）。

### App.vue —— 根组件
只有 `<router-view />`，所有页面按路由渲染。全局 reset 样式（margin/padding 清零）。

### router/index.js —— 路由表 + 守卫
```js
// 路由表（懒加载）：/home 首页、/spot/:id 景点详情、/order-confirm 确认订单、
// /pay 支付、/orders 订单列表、/order/:id 详情、/evaluation-submit 评价、
// /notices 公告、/user 个人中心、/profile 资料、/login 登录
// 路由守卫 beforeEach：
// 1) 残留 admin 令牌 → 清除并回登录页（游客端只允许游客）
// 2) 已登录访问 /login → 跳 /home
// 3) requiresAuth 页面无 token → 跳 /login
```
> meta.requiresAuth 标记需要登录的页面，守卫统一拦截。

### store —— Pinia 状态
- `store/index.js`：创建 pinia 实例
- `store/modules/user.js`：`useUserStore`，管理 token/userInfo，`login/getUserInfo/logout` 三个 action，登录后写 localStorage

## 5.2 api 包 —— 与后端接口一一对应

| 文件 | 调用的后端 | 说明 |
|---|---|---|
| `request.js` | — | axios 实例：baseURL `/api`，请求拦截器自动带 `Bearer token`，响应拦截器统一处理 `{code,msg,data}`（401 跳登录、非 200 弹 toast） |
| `user.js` | `/api/user/*` | 登录/注册/信息/改资料 |
| `spot.js` | `/api/spot/*` | 景点列表/详情 |
| `ticket.js` | `/api/ticket/*` | 票种/时段 |
| `order.js` | `/api/order/*` | 下单/支付/退款/列表/隐藏（已见） |
| `verify.js` | `/api/verify/*` | 核销 |
| `weather.js` | `/api/weather/*` | 天气 |
| `flow.js` | `/api/flow/*` | 客流 |
| `notice.js` | `/api/notice/*` | 公告 |
| `evaluation.js` | `/api/evaluation/*` | 评价 |

## 5.3 utils 包 —— 亮点工具

| 文件 | 作用 |
|---|---|
| `auth.js` | token 读写工具 |
| `storage.js` | localStorage 封装 |
| `date.js` | 日期格式化 |
| `validator.js` | 表单校验（手机号/密码等） |
| `gugongData.js` | ★ 故宫 15 座建筑坐标布局数据（中轴线参数化） |
| `dataSimulator.js` | ★ 无硬件依赖客流模拟引擎（双峰客流曲线、8:00-18:00 压成 30 秒回放、确定性预计算） |
| `threeScene.js` | ★ 故宫数字孪生 3D 场景（HLOD 分级渲染、Marching Squares 热力、3200 粒子速度场、SSAA+Bloom+ACES） |
| `crowdInteraction.js` | ★ 客流大屏交互（点击建筑看详情、粒子跟随） |

### threeScene.js 亮点速览（答辩重点）
```
- 三级 HLOD：近景高模 / 中景中模 / 远景 InstancedMesh 实例化
- Marching Squares 等值线热力场 + 32 级密度梯度
- 3200 粒子速度场：四维向量 + 光流尾迹 + 空间哈希斥力
- 半透明监测立柱 + IQR 滑动窗口异常检测
- SSAA 超采样 + UnrealBloom 泛光 + ACES 色调映射
```

## 5.6 一条完整前端链路（跟着走一遍）

```
Home.vue（3D 地球点国家）→ /spot/:id（景点详情）
→ OrderConfirm.vue（选票种时段数量，调 ticket + order/create）
→ Pay.vue（调 order/pay，alipay 跳收银台）
→ 支付回调 → OrderList.vue（状态 0→1）
→ OrderDetail.vue（看核销码）→ 管理员核销 → 状态 1→2
→ EvaluationSubmit.vue（已核销可评价）
```
