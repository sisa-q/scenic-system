## 0.1 这个项目是什么？

**数字化文旅景区票务与游客流量监测管理系统**（毕设项目，代号 bishe）。

一句话：游客在网页上选景点买票、到景区扫码核销入园；管理员在后台维护景点/票种/时段、看实时客流大屏；系统自动统计客流、推送天气预警，并用 Redis 扛高并发防超卖。

它由 **3 个前端 + 1 个后端 + 2 个基础设施** 组成：

| 部分 | 目录 | 技术 | 作用 |
|---|---|---|---|
| 后端 | `houduana` | Spring Boot 3.5 + Java 21 | 提供全部 API、业务逻辑、数据库、Redis、WebSocket |
| 游客端前端 | `web` | Vue 3 + Vant 4 | 游客用的 H5 网页（选景点→买票→支付→订单） |
| 管理端前端 | `admin` | Vue 3 + Element Plus | 管理员用的后台（景点/票种/订单/核销/客流大屏） |
| 安卓壳 | `scenic-android` | uni-app | 把游客端打包成安卓 App（web-view 套壳） |
| 数据库 | — | MySQL 8 | 持久化所有业务数据 |
| 缓存 | — | Redis 7 | 分布式锁（防超卖）+ 缓存三防 |

## 0.2 核心技术栈（面试常问，先背下来）

- **后端**：Spring Boot 3.5 / Spring Data JPA / Spring WebSocket / Redis (Lettuce) / JWT (jjwt) / BCrypt / Lombok / Maven / JaCoCo
- **前端**：Vue 3 (Composition/Options API) / Vant 4（游客端）/ Element Plus（管理端）/ Vue Router / Vuex / Axios / Three.js（3D 地球与客流大屏）/ ECharts
- **部署**：Docker Compose（MySQL8 + Redis7 + Spring Boot + Nginx）/ 多阶段构建 / 国内镜像源

## 0.4 三个环境配置（application.yml 家族）

Spring Boot 支持**多 profile（环境）**，用 `--spring.profiles.active=xxx` 切换：

| 文件 | 用途 |
|---|---|
| `application.yml` | 默认配置（localhost MySQL、Redis、mock 支付） |
| `application-local.yml` | 本地支付宝沙箱真实密钥（已被 .gitignore 忽略，不提交 Git） |
| `application-prod.yml` | 生产环境（Docker 里用环境变量注入） |

> ⚠️ 最重要的坑：**启动后端必须带 `local`** 才能启用支付宝，否则是模拟支付！
> 命令行：`mvn spring-boot:run -Dspring-boot.run.profiles=local`
> IDEA：Run Configuration → Active profiles 填 `local`

## 0.5 如何把项目跑起来（手把手）

**第一步：启动 MySQL 和 Redis**
- MySQL：端口 3306，库名 `digital_ticket`（后端启动时 JPA 自动建表，DataInitializer 自动种数据）
- Redis：端口 6379（**没启动也能跑**，后端有降级逻辑，只是缓存/锁失效）

**第二步：启动后端（必须带 local）**
```powershell
$env:JAVA_HOME='D:\bishe\tools\jdk-21.0.12+8'
D:\bishe\tools\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run "-Dspring-boot.run.profiles=local"
```
启动成功看到：`Started HouduanaApplication in 5.x seconds` 和 `[Pay] enabled=true, channel=alipay`

**第三步：启动游客端前端（web）**
```powershell
cd D:\bishe\web
E:\nodejs\npm.cmd run dev    # 默认 8080 端口，/api 代理到后端 8083
```

**第四步：启动管理端前端（admin）**
```powershell
cd D:\bishe\admin
E:\nodejs\npm.cmd run dev    # 默认 8081 端口
```

**默认账号**：
- 游客：注册一个新账号即可
- 管理员：`admin / admin123`（DataInitializer 自动预设）

## 0.6 一次完整业务流（理解系统在干嘛）

```
游客登录 → 首页看 3D 地球/景点 → 选景点 → 选票种+时段 → 下单
  → 支付（支付宝沙箱/模拟） → 管理员后台核销码 → 入园
  → 核销驱动客流统计 → 客流大屏实时展示 → 游客可评价/退款
```
> 这条链路贯穿全项目，学第 1~6 章时始终带着它，就知道每个文件在链路上扮演什么角色。
