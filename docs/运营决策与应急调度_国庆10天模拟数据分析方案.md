## 3. 运营决策智能体：具体分析

### 3.1 指标与公式（全部来自现有表，只读）
| 指标 | 公式 | 数据来源 |
|---|---|---|
| 日入园 / 承载率 | entered_today（或已核销 sum(quantity)）/ capacity | t_flow_stat / t_order / t_scenic_spot |
| 在园瞬时峰值 | MAX(current_visitors) | t_flow_stat（按小时） |
| 时段预约率 | booked / quota | t_time_slot |
| 销售额 | SUM(total_amount) WHERE status IN (1,2,5) | t_order |
| 票种占比 | 各 policy 销量 / 总销量 | t_order |
| 客单价 | 销售额 / 订单量 | t_order |
| 退款率 | 退款申请数 / 已支付订单数 | t_order |
| 核销率 | 已核销 / 已支付 | t_order |
| 环比 | （假期均值 - 节前均值）/ 节前均值 | 同表按日期范围聚合 |
| 高峰时段 | 按 use_time 小时桶（2h 桶）统计 | t_order（复用 FlowStatServiceImpl.hourlyDistribution 思路） |

### 3.2 三阶段分析要点
1. **节前（09-28~09-30）**：预售放量节奏（09-29 环比 +80%）；提示"备货、加派验票/安保、检查 10/1-10/3 时段配额"。
2. **假期（10-01~10-07）**：峰值判定（10/03 92.5% 超限）、高峰时段（10-11 时 + 15-16 时）、票种结构（成人 60% 主导、学生 15% 需关注）、累计销售额（≈1593 万）、退款率（整体 ≈2.3%，10/02 单日 8% 异常）。
3. **返程（10-06~10-07）**：回落至 47.5%→32.5%；余票充足 → 建议"淡季促销 / 转售窗口"；为节后环比提供基线。

## 4. 应急调度智能体：具体分析

### 4.1 事件库与阈值（对照四区阈值设计语言）
| 事件 | 阈值 | 级别 | 处置建议（模型输出） |
|---|---|---|---|
| 客流承载率 | >65% / >85% / >90% | 警戒/危险/超限 | 警戒：引导错峰；危险：限流准备；超限：暂停现场售票、强制分流 |
| 瞬时激增 | 1 小时 +5000 人或 +25% | 危险 | 启动限流、增开验票通道 |
| 时段售罄 | 预约率 ≥95% / 100% | 警告/危险 | 引导至临近时段；建议加开时段（写操作→确认卡） |
| 天气预警 | 降雨≥70% / 高温≥38 / 大风 / 严寒≤-10 | 按类型 | 雨天：改期/退改提示；高温：防暑；大风：停飞户外项目 |
| 退款激增 | 单日退款申请 ≥ 平日 3 倍 | 危险 | 排查原因（天气/服务/价格）、发布公告、临时放宽改期 |
| 系统降级 | Redis 不可用（已有自动降级） | 信息 | 提示限流/降级运行，观察恢复 |

### 4.2 处置动作分级（人在回路：写操作必须确认卡）
- **只读建议**（直接输出）：错峰引导、限流公告文案、天气提示、增开时段建议。
- **写操作（弹确认卡 → /api/agent/confirm 执行）**：
  - `publish_notice`：发布应急公告（如"10/3 承载率超限，建议错峰预约"）。
  - `dispatch_add_slot`：调度加开时段（如"10/3 下午加开 16:00-18:00 时段"），调用现有时段新增逻辑。
- 确认卡文案复用现有 `preview()` 机制（"将执行 X，确认后生效"）。

## 8. 模拟数据生成器：时间压缩（1 天 = 30 秒）与全显示同步的具体描述

### 8.1 与现有引擎的关系（现状即"1 天 = 30 秒"）
管理端大屏 `admin/src/utils/dataSimulator.js` 已经是"一天压缩 30 秒"的确定性模拟：
- `SIM_CONFIG`：8:00~18:00 共 10 小时，`playSeconds=30`，`totalEntries=80000`（故宫日承载上限量级），`orderRate=0.975`，`avgStayMin=180`（停留 3 小时）；
- `SimulationEngine`：预计算分钟级曲线 `entryRate → cumEntries → inPark`（入园速率 × 停留时长三角分布卷积），`getStateAt(hour)` 支持任意时刻查询（拖动进度条即调用），`getSummary()` 给全天汇总；
- `TimeController`：`speed=(18-8)/30=1/3 小时/秒`，**单一虚拟时钟**循环推进 8→18 点，`onTick(hour)` 同时驱动热力场/粒子/监控柱/统计面板/时间条/人群交互 → **所有显示同步**；支持暂停、调速、拖动；
- 双数据引擎：`sim`（前端模拟，默认）/ `real`（后端 `/ws/flow` WebSocket + `/api/flow/realtime`，realScale 缩放）。

**国庆 10 天生成器 = 把同一套引擎从"单日"扩展为"10 天连续"，不改变架构。**

### 8.2 时间模型
- 虚拟时间 = `(dayIndex, hour)`：dayIndex∈[0,9] 对应 09-28 ~ 10-07；hour∈[8,18]。
- 播放时长：**1 天 = 30 秒 → 10 天 = 300 秒（5 分钟）连续循环**；压缩比 1200:1（10 小时 ÷ 30 秒）。
- 两种播放模式：
  - **连续模式（默认）**：300 秒自动播完 10 天，日期/阶段标签（如"10/03 周六 · 假期峰值"）随进度自动切换；
  - **按日模式**：点选某一天，该天以 30 秒循环播放（等价于现状），日期选择与播放互相同步。
- 支持暂停 / 1×·2×·4× 调速 / 拖动进度条（拖动 = `setTime(dayIndex, hour)`，所有面板瞬移同步）。

### 8.3 剧本 DAY_PLAYBOOK（唯一事实来源）
每天只需 6 个"标定参数"，曲线形状由引擎统一生成（与现有公式完全一致）：
```
{ date:'2026-10-03', dayName:'周六', phase:'假期峰值',
  totalEntries:74000,             // 日入园总量（承载率 92.5%）
  amQuota:44000, pmQuota:36000,   // 时段配额
  amBookedRatio:1.00, pmBookedRatio:0.88,  // 时段预约率
  refundRate:0.03,                // 当日退款率
  weather:{ text:'晴', temp:34, rainProb:0, windLevel:2 } }
```
10 天参数即第 2.2 / 2.3 / 2.5 节表格（客流曲线、时段配额、天气剧本、退款率）。

### 8.4 生成与同步（三个环节共用同一剧本）
1. **前端显示**：`SimulationEngine` 按天构建 `dayCurves[dayIndex]`（公式不变）；`TimeController` 增加 `dayIndex` 推进与 `setTime(day,hour)`；大屏所有面板监听同一个 `(dayIndex,hour)` tick → 所有显示同步。
2. **后端落库（给运营/应急智能体）**：生成器用同一份剧本 + 同一确定性公式，把分钟级曲线降采样到小时写入 MySQL：
   - `t_flow_stat`：每小时一条，`current_visitors=inPark`、`entered_today=cumEntries`（取整）；
   - `t_time_slot`：国庆窗口每天 2 段（08-12 / 14-18），quota 44000/36000，`booked` 按预约率剧本；
   - `t_order`：按 entryRate ÷ 平均 2 张/单 生成，`use_time` 落在虚拟时刻，状态分布按剧本（10/2 退款率 8%）；
   - `t_evaluation` / `t_pay_transaction` 配套。
3. **一致性保证**：前端曲线与后端数据**同源派生（同一公式、同一参数）** → "画面播到 10/3 12:30 在园 22,200 人" == "工具查询 10/3 数据 22,200 人"，无随机、可复现。

### 8.5 real 模式（WebSocket）与智能体联动
- 大屏切 `real` 时，后端按**服务器端虚拟时钟（300 秒循环）**把同一剧本值推送到 `/ws/flow`（每 5 秒一帧）→ realScale≈1，热力/粒子/统计与 sim 模式数值一致，两种模式看到同一份国庆数据。
- 运营/应急对话按当前虚拟 `(dayIndex)` 查询后端 → 分析结果与大屏画面同刻同值（例：播到 10/3 时问"现在承载率多少" → 返回 92.5%，大屏同步超限红态）。
