# 数据库设计（10 张表）

> 数据库：MySQL 8 · `digital_ticket`；JPA `ddl-auto=update` 自动建表。

## 表清单
| 表 | 实体 | 说明 |
|---|---|---|
| t_user | User | 用户（游客/管理员） |
| t_scenic_spot | ScenicSpot | 景点 |
| t_ticket_policy | TicketPolicy | 票种（成人/学生票） |
| t_time_slot | TimeSlot | 预约时段 |
| t_order | Order | 订单（状态机） |
| t_pay_transaction | PayTransaction | 支付流水 |
| t_verify_record | VerifyRecord | 核销记录 |
| t_evaluation | Evaluation | 评价 |
| t_notice | Notice | 公告 |
| t_flow_stat | FlowStat | 客流统计快照 |

## 核心表结构

### t_order（订单）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK 自增 | |
| user_id | BIGINT | 下单用户（索引） |
| order_no | VARCHAR(32) UNIQUE | 业务订单号（支付宝 out_trade_no） |
| policy_id / slot_id | BIGINT | 票种 / 时段 |
| quantity | INT | 数量 |
| total_amount | DECIMAL | 总金额 |
| status | TINYINT | 0待付/1已付/2已核销/3已退/4失效/5退款中（索引） |
| pay_time / use_time / refund_time / refund_request_time | DATETIME | 各节点时间 |
| user_visible | TINYINT | 游客是否可见（可隐藏） |

### t_time_slot（时段，防超卖关键）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| policy_id | BIGINT | 所属票种（索引） |
| start_time / end_time | DATETIME | 场次时间（索引） |
| quota | INT | 总名额 |
| booked | INT | 已约数（扣减单位） |
| status | TINYINT | 1启用 0关闭 |

## 核心关系
```
ScenicSpot 1 ── N TicketPolicy 1 ── N TimeSlot
Order ── N ── 1 User
Order 1 ── 1 PayTransaction / VerifyRecord
Order ── N ── 1 Evaluation（按 spot 聚合）
```

## 索引设计
- t_user：phone（登录查询）
- t_order：user_id、status、slot_id（订单筛选/库存校验）
- t_time_slot：policy_id、start_time（时段查询）
- t_ticket_policy：spot_id（景点→票种）
